# 🍽️ Full-Stack Restaurant & Food Ordering Application

A complete full-stack **restaurant and food ordering web application** developed in **2022** using **Next.js, React.js, JavaScript, Node.js, and MongoDB**, and deployed using **Vercel**.

The project was built as a practical full-stack development project, implementing a complete restaurant workflow for both **customers and restaurant administrators**.

## ✨ Features

### 👤 Customer Side
- Browse the restaurant's food menu
- Explore different food products
- View individual product details
- Add food items to the order
- Manage selected items before ordering
- Provide customer and delivery information
- Place food orders
- Receive order confirmation/status

### 🛠️ Admin Panel
- Dedicated restaurant administration interface
- View incoming customer orders
- View customer and order details
- Confirm customer orders
- Add new food products
- Delete existing products
- Manage the restaurant's available menu
- Manage products and orders through the backend

## 🚀 Getting Started

Install the project dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Then open:

```text
http://localhost:3000
```
